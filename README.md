# Fun English English Training Centre - Website

Folder siap deploy (HTML statis + Tailwind CDN, tanpa backend).

## Isi folder
- index.html : Beranda (hero, keunggulan, video suasana belajar, statistik, FAQ, form pendaftaran, lokasi cabang, Yuk Gabung Fun English, Tim Pengajar)
- tentang-kami.html : Tentang Kami (profil lembaga, mengapa kami, profil pengajar, suasana belajar, semua video kegiatan)
- program-kids.html : Fun Kids English (TK & SD)
- program-teen.html : Teen & Academic English (SMP & SMA)
- program-general.html : General & Professional (umum, School Partnership, Company Training)
- promo.html : Promo, penawaran menarik, dan Placement Test gratis
- privacy.html : Kebijakan Privasi
- assets/ : logo, favicon, foto, video, dan poster video

PENTING: upload SELURUH folder (termasuk assets), atau zip-nya. Jangan hanya upload index.html.

## Cara deploy
1. Netlify: buka app.netlify.com/drop lalu drag seluruh folder atau file zip. Untuk update, drag ulang ke site yang sama.
2. Vercel: drag folder ke vercel.com/new, atau jalankan `npx vercel --prod` di dalam folder.
3. Hosting biasa: upload seluruh isi folder ke public_html.

## Menu dan tombol
- Menu navbar: Beranda, Program (3 halaman), Tentang Kami, Promo, Lokasi Tersedia, Penawaran Menarik, Hubungi Kami, dan tombol TANYA KAMI.
- Lokasi Tersedia, Penawaran Menarik, dan TANYA KAMI membuka jendela di dalam halaman.
- Tombol Daftar Program Ini di halaman program membuka formulir Beranda dengan program sudah dipilih.
