# Fun English English Training Centre - Website

Folder siap deploy (HTML statis + Tailwind CDN, tanpa backend).

Isi folder:
- index.html : halaman utama
- privacy.html : Kebijakan Privasi
- assets/ : logo, favicon, flyer, foto cabang, pengajar, kegiatan, Company Training, dan video kegiatan

PENTING: upload SELURUH folder (termasuk assets), atau zip-nya. Jangan hanya index.html.

Cara deploy:
1. Netlify: buka app.netlify.com/drop lalu drag seluruh folder atau file zip. Untuk update, drag ulang ke site yang sama.
2. Vercel: drag folder ke vercel.com/new, atau jalankan `npx vercel --prod` di dalam folder.
3. Hosting biasa: upload seluruh isi folder ke public_html.
